START HERE - Distribution Desk

This folder contains the complete standalone Next.js source for deployment on Vercel with Supabase.

1. Extract the ZIP first (do not run files inside the ZIP).
2. Open this folder in your editor. You should see app, components, lib, supabase, package.json, and DEPLOYMENT.md.
3. Follow DEPLOYMENT.md to create your Supabase project, apply all five migrations in chronological order, and configure environment variables.
4. Install Node.js 22. Run npm ci in this folder to download the dependencies.
5. Run npm run dev for local development, or connect the folder to a Git repository and deploy with Vercel.

The application uses the Supabase JavaScript SDK over HTTPS. Configure the public Supabase URL and publishable key, the server-only SUPABASE_SECRET_KEY (or legacy SUPABASE_SERVICE_ROLE_KEY), the stable APP_ENCRYPTION_KEY, and your production HTTPS app URL. A direct database connection string is not required.

The archive is small because node_modules and generated build files are excluded. npm ci installs the dependencies from package-lock.json. Your Supabase and Vercel credentials must be configured separately. Keep all server keys out of public variables and source control.
